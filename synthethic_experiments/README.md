## Synthetic Experiments
This directory contains the code for the synthetic experiments conducted in the paper. 

There are three python scripts in this folder

- `generate_data.py': This scripts contain helper function to generate the synthetic data.
- `plot_functions.py': This script contains helper functions to plot the results of the experiments.
- `classification_experiments.py': This script contains the main code to run the experiments and plot the results. There's also a section (currently commented) in there that can be used to create the table with the relative error per M and U combo for the feature map.
